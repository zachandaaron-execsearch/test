# Newsletter Pre-Publish Checklist

Use this checklist before publishing any newsletter. All items should be checked.

---

## Content Quality

### Clinical Accuracy
- [ ] All study phases verified (Phase 1/2/3)
- [ ] Patient numbers and enrollment data fact-checked
- [ ] Endpoints and efficacy claims validated
- [ ] FDA designations/approvals cross-referenced
- [ ] Guest credentials verified via web search
- [ ] No claims accepted at face value from transcripts

### Language Standards
- [ ] No absolutist language (never, always, all, none, revolutionary, groundbreaking)
- [ ] No dramatic verbs (kill, destroy, dominate)
- [ ] Scientific language used ("showed" not "proved", "suggests" not "proves")
- [ ] Conditional language where appropriate (may, can, tends to)
- [ ] Quantified claims with specific numbers

### Editorial Quality
- [ ] Under 800 words (or appropriately shorter)
- [ ] Strong clinical hook in opening
- [ ] Would a clinical ops director forward this to their team?
- [ ] Limitations and counterpoints acknowledged
- [ ] Regulatory context included where relevant

---

## Structure & Format

### Organization
- [ ] Clear narrative flow
- [ ] Key insights are scannable
- [ ] Direct quotes attributed properly
- [ ] Technical terms used correctly (no oversimplification)

### Links & References
- [ ] Related past newsletters identified and bracketed for linking
- [ ] External sources cited where appropriate
- [ ] No broken or placeholder links

---

## Final Review

### Peer Review
- [ ] Clinical terminology reviewed by subject matter expert
- [ ] Tone appropriate for senior clinical ops audience
- [ ] No hype or marketing language

### Pre-Send
- [ ] Subject line compelling and accurate
- [ ] Preview text set
- [ ] Send list confirmed
- [ ] Mobile rendering checked
