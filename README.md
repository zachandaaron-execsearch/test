# Power Newsletter Workflow

A guided web app for creating clinical operations newsletters using Claude Projects.

## Overview

This app walks team members through a two-step newsletter creation process:

1. **Discovery** - Work with the Discovery Agent to develop your topic and create a narrative brief
2. **Creation** - Use the Newsletter Agent to write the final draft based on your brief

## Features

- Step-by-step guided workflow (Start → Discovery → Handoff → Creation → Review)
- Progress auto-saves to browser localStorage
- Copy-to-clipboard for easy handoff between steps
- Pre-publish quality checklist (8 items)
- Mobile-responsive design
- Clean "Power Newsletter" branding

## Workflow Steps

### Step 1: Start
Select your source material type:
- Podcast Transcript
- Internal Data/Analytics
- Customer Insights
- Brainstorm/Concept
- Industry News

### Step 2: Discovery
Open the Discovery Project and work through the guided questions to develop your angle.

### Step 3: Handoff
Paste and save the Narrative Brief generated by the Discovery Agent.

### Step 4: Creation
Open the Newsletter Project, paste your brief, and work with the agent to create your draft.

### Step 5: Review
Complete the pre-publish checklist:
- All clinical claims fact-checked
- No absolutist language
- Scientific language used
- Under 800 words
- Limitations acknowledged
- Related past newsletters linked
- Strong opening hook
- Would a clinical ops director forward this?
